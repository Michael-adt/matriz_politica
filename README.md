Matriz política (protótipo de teste)
Questionário online estático (HTML + JavaScript, sem servidor) com dashboard de resultado.
index.html: página única
style.css: visual
itens.js: perguntas e eixos (gerado da planilha). Para novos blocos, acrescentar objetos em blocos.
logica.js: pontuação (recodificação, média por eixo, coerência, alertas de qualidade)
app.js: telas (intro, perguntas, resultado com radar e abas por eixo)
Privacidade: as respostas ficam no navegador (localStorage). Nada é enviado a servidor.
Versão 0.1: apenas bloco A (Economia e Estado). Perguntas ainda não validadas com dados reais.
